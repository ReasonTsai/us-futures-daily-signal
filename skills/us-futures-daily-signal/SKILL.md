# US Futures Daily Signal

## Read the report

1. Read `data/latest.json` from the current project when it is available.
2. When running without the local project, retrieve `data/latest.json` from the configured GitHub repository through an available GitHub connector or its public raw-content URL.
3. Refuse to treat `status: not_generated` as an analysis.
4. Check `generated_at`, `latest_market_date`, each market's `data_time`, and `errors` before interpreting signals.
5. State clearly when the report is partial, stale, or missing a market.

## Interpret the report

- Translate `bullish`, `bearish`, `neutral`, and `mixed` into 偏多、偏空、中性、分歧.
- Treat events marked `strength: major` as important, but never as guaranteed trades.
- Explain `extreme_volume`, `ma_hold`, and `ma_reclaim` using their `reason` and `details`.
- Compare ES, NQ, and YM. Call a broad confirmation only when at least two markets agree.
- Mention daily price change, latest close, and volume only when they help explain the signal.
- Keep computation results distinct from interpretation; do not invent missing indicators.

## Respond

Return a concise Traditional Chinese report in this order:

1. 資料日期與完整性
2. 整體判斷
3. ES、NQ、YM 各自方向與重要事件
4. 市場共振或分歧
5. 訊號失效風險與資料來源限制

End with: `此為量化訊號整理，不構成投資建議。`
